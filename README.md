## 🧱 Sobre este proyecto Next.js

Proyecto enfocado en crear un sistema real de captación de clientes para negocios locales utilizando arquitectura serverless en AWS.

Desarrollé una página web conectada a un formulario que envía datos a una API construida con API Gateway + AWS Lambda, almacenando automáticamente la información en DynamoDB.

El objetivo es ayudar a negocios a construir su propia base de datos de clientes potenciales y preparar el camino para automatizaciones futuras como seguimiento, campañas y análisis de datos.

Arquitectura implementada:
• Frontend desplegado en Vercel
• API REST con Amazon API Gateway
• Procesamiento con AWS Lambda
• Almacenamiento en DynamoDB
• Registro de eventos y monitoreo con CloudWatch

Este sistema puede adaptarse para:
• Restaurantes que reciben pedidos por WhatsApp
• Bienes raíces que captan interesados en propiedades
• Negocios locales que necesitan organizar sus prospectos

Proyecto desarrollado como base para R.tech, enfocado en soluciones tecnológicas reales para generación de clientes.
